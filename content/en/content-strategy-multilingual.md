## The Multilingual Content Trap

Most organizations approach multilingual content wrong: they create content in one language, then translate it. This produces content that feels foreign in every language except the original.

The better approach: create content that's designed to travel.

### The Source Language Decision

Your source language shapes everything downstream. Consider:

- **English** as source: largest translator pool, most tooling support
- **Local language** as source: more authentic, but harder to scale
- **Language-agnostic brief**: write the brief in any language, create content natively in each

### Translation Memory

Translation memory (TM) stores previously translated segments. When similar text appears again, translators see the previous translation and can reuse or adapt it.

Benefits:
- Consistency across documents
- Faster translation (pay less for repeated segments)
- Terminology enforcement

Tools: Phrase, Lokalise, Crowdin, Weblate (open source)

### The Content Audit Framework

Before translating, audit your content:

```
Tier 1 — Translate immediately:
  - Homepage, product pages, checkout
  - High-traffic blog posts
  - Legal/compliance content

Tier 2 — Translate when resources allow:
  - Blog posts (medium traffic)
  - Help documentation
  - Email templates

Tier 3 — Machine translation + review:
  - Long-tail blog posts
  - User-generated content
  - Internal documentation
```

### SEO Considerations

Each language version needs its own SEO strategy:

- Keyword research in the target language (not translated keywords)
- Local link building
- hreflang tags on every page
- Separate sitemaps per locale

### Measuring Multilingual Content Performance

Track separately per locale:
- Organic traffic by language
- Conversion rate by language
- Bounce rate by language
- Time on page by language

Significant differences reveal localization quality issues, not just translation problems.

Content that resonates in one culture may fall flat in another. Build the feedback loops to find out.
