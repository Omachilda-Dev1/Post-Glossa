## 为什么大多数人在语言学习上挣扎

学习一门新语言是最有价值的智识冒险之一——然而大多数人在前三个月内就放弃了。原因不是缺乏天赋，而是缺乏**系统**。

### 遗忘曲线

赫尔曼·艾宾浩斯在19世纪80年代发现，除非我们主动复习，否则在24小时内会忘记约70%的新信息。

解决方案是**间隔重复**——在即将忘记之前以递增的间隔复习材料。

```bash
# 安装Anki CLI进行自动化闪卡复习
npm install -g anki-cli
anki-cli create-deck --name "英语词汇" --file words.csv
```

### 真正有效的沉浸式技术

- **跟读法**：听母语音频并同时重复，匹配节奏和语调
- **泛读**：阅读略高于你水平的内容
- **语言交换**：使用Tandem或HelloTalk等平台
- **媒体沉浸**：将手机和流媒体服务切换到目标语言

### 词汇的80/20法则

| 词汇量 | 覆盖率 |
|--------|--------|
| 100个词 | ~50% |
| 1,000个词 | ~85% |
| 10,000个词 | ~98% |

坚持胜过强度。每天三十分钟每次都胜过周末四小时的学习。
