## なぜほとんどの人が言語で苦労するのか

新しい言語を学ぶことは、最も充実した知的冒険の一つです。しかし、ほとんどの人は最初の3ヶ月以内に諦めてしまいます。理由は才能の欠如ではありません。**システム**の欠如です。

### 忘却曲線

ヘルマン・エビングハウスは1880年代に、積極的に復習しない限り、24時間以内に新しい情報の約70%を忘れることを発見しました。

解決策は**間隔反復**です — 忘れる直前に増加する間隔で素材を復習します。

```bash
# 自動化されたフラッシュカード復習のためにAnki CLIをインストール
npm install -g anki-cli
anki-cli create-deck --name "英語語彙" --file words.csv
```

### 実際に機能する没入技術

- **シャドーイング**: ネイティブ音声を聞きながら同時に繰り返す
- **多読**: 自分のレベルより少し上のコンテンツを読む
- **言語交換**: TandemやHelloTalkなどのプラットフォームを使う
- **メディア没入**: 電話とストリーミングサービスを目標言語に切り替える

### 語彙の80/20ルール

| 語彙サイズ | カバレッジ |
|-----------|-----------|
| 100語 | ~50% |
| 1,000語 | ~85% |
| 10,000語 | ~98% |

一貫性が強度を上回ります。毎日30分は、週末の4時間セッションを毎回上回ります。
